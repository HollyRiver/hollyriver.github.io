# Skills 아이콘 출처

각 로고의 상표권은 해당 소유자에게 있으며, 기술 스택 표기 목적으로만 사용한다.

| 파일 | 출처 | 비고 |
|---|---|---|
| python, r, julia, csharp, pytorch, huggingface, scikitlearn, sqldeveloper, pandas, numpy, plotly, matplotlib, seaborn, docker, git, github, claude | [Devicon](https://devicon.dev) 2.18.0 `*-original.svg` | MIT |
| linux | Devicon 2.18.0 `linux-plain.svg` | MIT · original(194KB) 대신 경량 단색판 |
| sas | [Wikimedia Commons: SAS_logo_horiz.svg](https://commons.wikimedia.org/wiki/File:SAS_logo_horiz.svg) | Public domain(상표 등록) · 워드마크를 제외하고 S 심볼 경로만 추출, 정사각형 viewBox로 재구성 |
| vllm, wandb | [Simple Icons](https://simpleicons.org) 16.36.0 (`vllm`, `weightsandbiases`) | CC0 · 브랜드 색(#30A2FF, #FFBE00)을 `fill`로 주입 |

FSDP는 PyTorch 기능이라 별도 로고가 없어 아이콘 없이 표기.
