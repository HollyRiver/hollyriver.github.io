# hollyriver.github.io

강신성(Shinsung Kang)의 데이터 사이언스 포트폴리오 — **https://hollyriver.github.io/**

- 빌드 도구 없는 정적 사이트(HTML·CSS·JS), GitHub Pages로 배포
- 웹에서는 프로젝트별 접기/펼치기, 브라우저 인쇄(PDF 저장) 시에는 모든 프로젝트를 펼친 A4 문서로 출력

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 본문 (About · Education · Experience · Certificates · Skills · Publications · Featured Projects) |
| `css/style.css` | 화면·모바일·인쇄(A4) 스타일 |
| `js/main.js` | `::details-content` 미지원 브라우저에서 인쇄 시 프로젝트를 펼치는 폴백 |
| `figure/` | 프로젝트 도식·결과 그림 |
| `icons/` | 기술 스택 아이콘 |
