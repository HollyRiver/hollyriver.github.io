SurvLLM 연구 2025.10 - 현재

# Situation
* LLM의 능력을 생존분석에 적용함으로써, 기존 생존분석에 활용되는 태뷸러 데이터 이외에도, 분석 환자에 대한 중요한 정보를 가지고 있는 텍스트 데이터를 활용하고자 함
* 의무기록지 텍스트를 입력으로 환자의 생존함수를 도출함에 있어, 텍스트의 규격화되지 못한 형태로 인해 실제 적용에 어려움이 존재
* 텍스트를 특정 형태로 규격화한 뒤, 규격화된 텍스트를 기반으로 안정적인 생존함수 도출이 가능하도록 만들고자 함

# Task
* 원본 의무기록지 텍스트의 규격화 페이즈를 전면 담당
* 동료 연구자 이탈로 인해 소스 데이터에서부터 학습 및 결과 데이터 처리 및 레이블링에 해당하는 부분을 위임
* 위임받은 업무 중, 오픈소스 LLM 기반 데이터 선호도 레이블링에서 무작위에 가깝던 퍼포먼스를 개선

# Action
## 개요
* MIMIC-IV v3.1 Admissions, Patients 테이블과, MIMIC-IV-Note v2.2 Discharge 테이블을 활용하여 모델 학습 및 테스트 수행
* 원본 의무기록지 텍스트와, 약속된 규격으로 정리된 해당 텍스트의 쌍으로 구성된 메시지 데이터셋을 활용하여 Llama-3.1-8B-Instruct 모델에 SFT 적용
* SFT 모델에 대해 하나의 의무기록지에 대해 5개의 응답을 확률적으로 생성하고, 각 응답의 순위를 인간 주석자 또는 오픈소스 LLM이 평가. 총 200개의 레이블링 대상 중 130개를 직접 레이블링하였음
* 의무기록지 별 5C2, 10개의 응답으로 구성된 선호도 데이터셋을 활용하여, SFT 모델을 선호도 조정 (DPO / PPO) 방법으로 이어서 학습. 선호도 데이터셋의 인간/AI 구분과 선호도 조정 방법론의 구분으로 총 4가지 형태를 비교
* 최종 학습된 모델로 의무기록지 텍스트를 규격화하여, 다음 페이즈인 생존함수 도출 부분에 전달

## 세부 사항
* wandb를 사용하여 훈련 로그 및 지표 곡선을 확인하고, 적절한 하이퍼파라미터 세팅과, 검증 데이터셋 기반 최적 체크포인트 선택
* 위임받은 업무 중 오픈소스 LLM 기반 선호도 레이블링의 기존 성능을 개선하기 위해, 프롬프트 구체화 및 구조화, 퓨샷, 추론 활성화 등의 테크닉을 활용
* 검증 손실이 존재하지 않는 PPO 체크포인트 선택 단계에서, 생성된 검증 텍스트들의 품질 정도를 정량/정성적으로 비교

# Result
* 학습된 모델의 모든 출력이 약속된 규격 준수 확인, 학습 데이터의 양적 부족으로 인한 품질 문제 식별됨
* 최종 생존함수 도출 결과에서 베이스라인 모델인 Cox, DeepHit에 대하여 Harrell's C-index 10% 이상 개선됨
* 오픈소스 LLM 기반 선호도 레이블링과 인간 선호도 레이블링에 대하여, 무작위 선호도 쌍의 순위 동일 확률이 기존 0.5 수준에서 0.7 정도로 크게 개선됨
