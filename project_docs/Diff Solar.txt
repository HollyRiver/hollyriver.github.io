# Situation
* -120, -90, -60, -30, 0분에 해당하는 과거 위성 이미지를 기반으로, 30, 60, 90, 120분 미래의 일사량 이미지를 예측. 이전 연구인 AC U-Net에서부터 이어진 연구
* 픽셀 단위 예측의 정확성과, 예측 이미지의 지각적 사실성을 확보하기 위해 디퓨전 모델을 활용
* 진행중인 연구에서 석사과정 연구생이 졸업 및 취업하게 되며 이탈하고, 그 과정에서 실험 및 성능이 정체되어 있었음
* 해당 자리에 기존 실험 인계 및 베이스 모델 예측 성능 개선을 위해 연구 중도에 참여

# Task
* 베이스 디퓨전 모델의 예측을 보정하는 후처리 모듈 담당
* 결과에 대한 정량/정성적 분석을 수행

# Action
## 개요
* 한반도 상공 정지궤도 기상위성인 천리안 2A호에서 촬영된 이미지에 검증된 물리 모델을 활용하여 픽셀 단위로 태양 에너지를 추정. 해당 일사량 맵 데이터를 모델 훈련, 검증, 테스트에 활용
* v-prediction 기반 Base 모델 훈련, 훈련/검증/테스트 이미지에 대하여 8개의 확률적 예측 생성, 훈련/검증/테스트 이미지에서 잔차를 계산하고, 노이즈에서 해당 잔차를 예측하는 x0-prediction 기반 Refiner 모델 훈련, 객체마다 8개씩 생성된 이미지에 예측된 8개의 잔차 이미지를 더하고, 평균 앙상블을 통해 최종 결과 산출
* 최종 결과의 픽셀 MSE가 집중되는 영역을 실제 지도와 비교 분석하여, 오차의 형태를 구조화

## 세부 사항
* Claude Code CLI를 통해 기존 소스코드 분석 및 프로젝트 기반 마련
* Refiner 모델에서 하나의 객체에 대해 8개의 서로 다른 다양한 잔차를 학습함으로써 Base 모델의 확률적 잔차 구조를 최대한 반영하고자 시도
* 픽셀단위 MSE 1차원 스칼라를 10개 구간으로 클러스터링하여 오차 지도를 그리고, 해당 오차 구조를 두 가지로 설명
* 편서풍 및 하계 몬순 제트 기류로 좌하단의 고오차 지대를 사전 정보 없이 모델이 예측하게 되어 높은 오차가 발생한다고 설명
* 내륙의 경우 산맥 구조가 빚어내는 상승기류와 구름 생성이 높은 오차를 발생시킨다고 설명

# Result
* 픽셀단위 지표와 지각적 사실성을 종합적으로 충족
* 30, 60, 120에서 모든 베이스라인 대비 가장 낮은 MSE와 MAE 달성, 90에서는 이전 연구 모델인 AC U-Net 다음으로 우수
* 앙상블 없는 모델의 경우 지각적 사실성 지표인 FID와 LPIPS가 베이스라인 대비 24-54%까지 감소
* Refiner가 앙상블 시 예측의 고유 Sharpness를 키워, Base 모델 멤버의 산포도를 교정함으로써 예측 정확도를 향상시킴을 식별
