# Situation
* 특정 텍스트가 인간이 작성했는지, LLM이 생성했는지를 텍스트에서 추출한 피처를 기반으로 모델링
* 텍스트의 통계적 특성을 비교함으로써 인간과 LLM 간 설명 가능한 차이를 식별
* 첫 연구 경력

# Task
* Perplexity 제안 및 구현, LDA·MLP·평가 지표 코드 오류 검토와 버전 관리
* 피처 분포 시각화 및 해석

# Action
## 개요
* 질의응답 웹사이트 Quora를 데이터 소스로 활용하여, 자체 구축된 벤치마크 데이터를 학습 및 평가에 활용
* Llama-3.1-8B 모델 기반 Perplexity 계산, 동료 연구자가 계산 및 설계한 문체 분석 기반 특징 및 내용 분석 기반 특징과 통합하여 MLP로 다중 분류 모델 학습
* 평가 데이터에서 다섯 범주별 확률값을 그대로 다중 분류에 활용하거나, 네 개의 LLM 범주 확률을 통합하여 인간/LLM의 이진 분류에 활용
* 문체 분석 기반 특징과 Perplexity의 범주별 분포를 비교


## 세부 사항
* 딱히 없는 듯?

# Result
* 이진 분류에서 정확도 0.9778, 다중 분류에서 정확도 0.8598을 기록
* 다른 통계적 피처들에 Perplexity를 추가하였을 때, 이진 분류의 오분류율 44.54% 감소, 다중 분류에서의 오분류율 23.81% 감소
* 사용된 통계적 피처들은 Perplexity가 보유하고 있지 않은 정보를 다수 포함함을 유추 가능
* 인간 텍스트의 Perplexity가 LLM 텍스트의 Perplexity보다 높은 평균에서 높은 분산으로 나타남
