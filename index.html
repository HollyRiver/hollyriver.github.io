LLM 기반 생존분석 연구 SurvLLM 연구 진행중

의무기록지 텍스트를 입력으로 생존분석을 수행하는 2단계 파이프라인
개요
 고전적인 태뷸러 데이터를 넘어, MIMIC-IV-Note 데이터셋 의무기록지 텍스트를 사용하여 생존함수까지 계산해내는 2단계 파이프라인. 해당 과정에서 LLM의 생존분석 태스크에 대한 추론 능력과 적합성을 파악.
1

텍스트 규격화 — 오픈소스 LLM에 QLoRA를 이용하여 SFT와 선호도 조정(DPO/PPO)을 적용, 규격화되지 않은 의무기록지 텍스트를 약속된 문장 형태로 변환

2

생존분석 — 규격화된 문장을 파인튜닝된 LLM 기반의 SurvLIFT에 입력하여 생존함수 Ŝ(t)를 추정

기여
 Phase 1 전면 담당. 데이터 구축, SFT, 선호도 조정에 필요한 데이터 레이블링(200건 중 130건 직접 수행), DPO 및 RM+PPO로 구분되는 선호도 조정 프로세스 직접 설계 및 학습. 생성된 규격화 문장을 15개 임상 피쳐로 파싱해 Phase 2에 전달

인간/LLM 생성 텍스트 판별 연구 LLMdetector KCI 등재 · 공동 1저자

인간 작성 텍스트와 LLM 생성 텍스트를 피처 기반으로 판별
개요
 Quora에서 수집된 질의응답 텍스트 데이터와, 해당 질의에 대한 LLM 생성 텍스트 데이터를 해석 가능한 통계적 피처로 판별. 그룹 별 통계적 피처의 분포 차이를 분석.

어휘 밀도·가독성 지수 등 문체적 통계량과, LDA 토픽 분포, Perplexity를 피처로 사용한 MLP로 분류 모델 구성

인간 vs LLM의 이진 분류 및 Human·GPT·Gemini·Claude·DeepSeek의 다중 분류 태스크를 각각 진행

성과
 이진 분류 정확도 0.9778, 다중 분류 정확도 0.8598 달성. 인간 perplexity가 LLM 대비 평균적으로 약 2배 높음을 식별
기여
 Perplexity 제안 및 구현, 결과 시각화, LDA·MLP·평가 지표 코드 오류 검토와 버전 관리, 담당 파트 논문 집필 및 관련 연구 조사

시계열 전이학습 베이스라인 실험 인프라 TSTF IEEE Access 논문 기여

레거시 Keras 실험을 PyTorch로 단독 재구현하고, 데이터셋당 500개 모델 앙상블 실험을 멀티 GPU로 자동화
문제
N-BEATS 전이학습 논문(IEEE Access)의 비교 실험에 필요한 PatchTST 베이스라인이 레거시 Keras 코드로는 재현·확장이 어려운 상황. 타겟 데이터셋 7종 × 손실함수 5종 × 모델 100개의 실험 매트릭스를 감당할 인프라가 필요
접근
HuggingFace PatchTST 백본을 M4 데이터로 부트스트랩 사전학습한 뒤 head를 교체(Transformer/LSTM/MLP)해 파인튜닝하는 전이학습 파이프라인을 PyTorch로 구축하고, median·지수 가중 앙상블로 최종 예측을 산출. 21개 실험 태스크를 multiprocessing 큐와 GPU 라운드로빈으로 자동화 — 결과 존재 시 스킵하는 재시작 안전 설계로 L40S 2-GPU 활용률 98%를 달성
품질 기여
원본 실험 코드의 결함(MASE 손실 오구현, MAPE의 0값 발산, 데이터 분할 분포 불일치)을 발견·문서화하고 방어 로직을 반영. 베이스라인 실험 결과는 논문 최종본에 수록
역할
torch/ 디렉토리 100% 단독 구현 및 결과 집계·보고 (논문 Acknowledgement 기재)
