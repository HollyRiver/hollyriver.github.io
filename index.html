데이터
MIMIC-IV v3.1, MIMIC-IV-Note v2.2
  • Harrell's C-index+10% 이상Cox·DeepHit 대비, 파이프라인 최종 결과
  • AI·인간 선호도 일치율0.5 → 0.7무작위 응답 쌍의 순위 일치 확률
  • 출력 규격 준수100%최종 모델의 전체 출력 기준

배경 Situation

  • LLM을 생존분석에 활용하여, 기존 생존분석에 필요한 태뷸러 데이터 이외에도, 분석 환자에 대한 중요한 정보를 포함하는 텍스트 데이터를 활용하려는 연구
  • 의무기록지 텍스트는 작성 형식 및 분량이 통일되지 않아, 원문을 그대로 사용할 경우 생존함수를 안정적으로 도출하기 어려움
  • 텍스트를 약속된 문장 형태로 규격화하고, 이를 기반으로 생존함수를 추정하는 2단계 구조를 이용

역할 Task

  • 원본 의무기록지 텍스트를 규격화하는 Phase 1 전면 담당
  • 동료 연구자 이탈로 인해 소스 데이터 가공부터 학습, 결과 데이터 처리, 레이블링 일부까지 위임받아 수행
  • 위임받은 업무 중 오픈소스 LLM 기반 선호도 레이블링에서 무작위에 가깝던 퍼포먼스를 개선

수행 Action

학습 파이프라인

  1. 데이터 구축: MIMIC-IV v3.1의 Admissions·Patients 테이블과 MIMIC-IV-Note v2.2의 Discharge 테이블을 활용하여 훈련·검증·테스트 데이터 구성
  2. SFT: 원본 의무기록지에 대하여 의료 도메인 지식을 가진 연구원이 레이블링한 규격화 문장 100개 쌍의 메시지 데이터셋으로 Llama-3.1-8B-Instruct 모델에 SFT 적용
  3. 선호도 레이블링: SFT 모델이 의무기록지당 5개 응답을 확률적으로 생성하고, 인간 주석자 또는 오픈소스 LLM이 순위 평가. 인간 레이블링 대상 200건 중 130건 직접 수행
  4. 선호도 조정: 의무기록지당 5C2 = 10쌍, 총 2,000쌍의 선호도 데이터셋으로 SFT 모델을 이어서 학습. 퍼포먼스 비교를 위해 선호도 레이블링 방법(인간/AI) × 선호도 조정 알고리즘(DPO / Reward Model + PPO)의 4가지 조합 비교
  5. 결과 전달: 사후학습을 마친 모델에 vLLM의 연속형 배치를 사용하여 추론을 수행. 의무기록지 테스트 데이터를 규격화한 뒤, Phase 2인 SurvLIFT에 전달

세부 사항

  • 기존 라이브러리 활용: TRL, PEFT, datasets 등 HuggingFace 제공 라이브러리와 vLLM을 적절하게 활용하여 구현 및 추론에 필요한 시간을 최소화
  • 사후학습 세부 설정: 매우 긴 토큰의 텍스트를 적절하게 학습시키기 위해 QLoRA(NF4, r=64), Assistant Only Loss를 공통으로 사용. 선호도 조정에는 병합 후 재양자화 대신, LoRA를 policy와 reference로 두 번 로드하여 양자화 오차 해소
  • 학습 모니터링: wandb를 사용하여 훈련 로그 및 지표 곡선을 추적하여 적절한 하이퍼파라미터를 세팅하고, 검증 데이터셋을 기반으로 최적의 체크포인트 선택
  • AI 레이블링 개선: 오픈소스 LLM 기반 선호도 레이블링의 기존 성능을 개선하기 위해 프롬프트 구체화 및 구조화, 퓨샷 예시 주입, 추론 활성화 등의 테크닉을 활용
  • 강화학습 기반 알고리즘의 체크포인트 선택: 검증 손실이 제공되지 않는 PPO의 경우, 체크포인트별로 생성한 검증 텍스트들의 품질을 정량·정성적으로 비교하여 인간 피드백 기반으로 직접 선택

성과 Result

  • 학습된 모델의 모든 출력이 약속된 규격을 준수함을 확인. 학습 데이터의 양적 결여로 인해, 문장형 묘사 자체의 품질 문제 식별됨
  • 최종 생존함수 추정에서 베이스라인 모델인 Cox, DeepHit 대비 Harrell's C-index 10% 이상 개선
  • 인간·AI 선호도 레이블 간 순위 일치 확률을 무작위 수준인 0.5에서 약 0.7로 개선

배경 Situation

  • 과거 2시간 이전부터 현재까지 30분 간격으로 관측된 위성 일사량 이미지 5장으로, 30·60·90·120분 후의 일사량 이미지를 예측. 선행 연구 모델인 AC U-Net의 후속 연구
  • 기존 LSTM·U-Net 등의 Regression 계열 모델은 우수한 픽셀 단위 예측 성능을 보이나, 이미지의 국지적 정보를 흐릿하게 뭉개는 한계가 존재
  • 예측의 픽셀 단위 정확성과 함께, 지구과학 분야에서 중요한 이미지의 지각적 사실성을 동시에 확보하기 위해 디퓨전 모델 채택
  • 연구에 참여한 석사과정 학생의 졸업 및 취업으로 인한 이탈 이후 실험과 성능 개선이 정체된 상황에서, 지원 역할로 참여

역할 Task

  • Base 디퓨전 모델의 예측을 보정하는 후처리 모듈(Refiner) 설계 및 학습
  • 결과에 대한 정량적·정성적 분석 수행

수행 Action

학습 파이프라인

  1. 데이터: 한반도 정지궤도위성 천리안 2A호의 이미지에 검증된 물리 모델을 적용하여, 픽셀 단위로 태양 에너지를 계산. 계산된 일사량 맵(512×512, 30분 간격)을 훈련·검증·테스트에 활용. 동료 연구원에게서 제공받음
  2. Base 모델: 전반부 담당 연구원에게 Base 디퓨전 모델로 훈련·검증·테스트 전 구간에서 각 시간별로 생성된 확률적 예측 8개 수령
  3. 잔차 계산: 훈련·검증·테스트 전 구간에서 서로 다른 8개의 Base 예측과 실제 맵의 차이인 잔차를 계산
  4. Refiner: 훈련 데이터의 과거 일사량 맵 5장과, Base 예측을 조건으로, 노이즈에서 잔차를 직접 복원하는 x0-prediction 기반 소형 U-Net 훈련. 검증 오차 기반 최적 체크포인트 선택. 예측 시간(30-120분)마다 별도로 모델 훈련
  5. 앙상블: 테스트 데이터에 대해서 Base 예측 8개 각각에 Refiner가 추정한 잔차를 더한 뒤 평균 앙상블로 최종 예측 산출

세부 사항

  • 코드베이스 인수: Claude Code CLI를 사용하여 기존 소스코드를 분석함으로써, 신속하게 실험 구조를 파악하고, 후속 작업의 기반을 마련
  • 잔차 분포 학습: 특정 시각 하나에 대해 서로 다른 8개의 잔차를 학습시켜, Base 모델 잔차의 확률 구조를 최대한 반영
  • 오차 지도 분석: 테스트 전체의 픽셀 단위 MSE를 10개 구간의 k-means로 군집화하고, 오차 지도를 실제 지도와 대조하여, 고오차 지대의 구조를 두 가지로 설명
    • 남서쪽 경계: 편서풍 및 하계 몬순 제트 기류를 따라 남서쪽에서 이미지 외부에서 유입되는 구름을, 모델이 사전 정보 없이 예측해야 함
    • 내륙 산지: 내륙의 경우 태백산맥과 같은 구조가 상승기류와 구름을 생성

성과 Result

  • 픽셀 단위 정확성과 지각적 사실성을 종합적으로 충족
  • 30·60·120분 예측에서 모든 베이스라인 대비 가장 낮은 MSE와 MAE 달성, 90분에서는 선행 연구 모델인 AC U-Net에 이어 두 번째로 우수
  • 최종 모델은 AC U-Net 대비 FID 26~54%, LPIPS 24~28% 감소. 앙상블 없는 단일 예측은 모든 예측 시점에서 학습 기반 모델 중 가장 낮은 FID 기록
  • Refiner가 예측의 선명도를 높여, Base 모델 멤버 간 산포를 교정함으로써 예측 정확도를 향상시킴을 식별. CRPS(Continuous Ranked Probability Score)의 커널을 분해하여 분석했을 때, 산포 증가가 앙상블 평균의 정확도 개선으로 이어짐을 식별

  • 다중 분류 정확도 · F1-Score0.8598 · 0.8607인간 + LLM 4종의 5개 출처 · Macro 평균
  • Perplexity 추가 효과오분류율 −44.64%이진 분류 · 다른 피처만 쓴 모델 대비

배경 Situation

  • 텍스트의 인간 작성, LLM 생성 여부를 텍스트에서 추출한 피처를 기반으로 판별하는 연구
  • 텍스트 자체를 분류 모델에 입력하지 않고, 추출된 통계적 특성을 비교함으로써 인간과 LLM 간의 설명 가능한 차이를 식별하는 것이 목표
  • 학부연구생으로 참여한 첫 연구

역할 Task

  • Perplexity 피처 제안 및 구현
  • 코드 오류 검토와 버전 관리
  • 피처 분포 시각화 및 해석

수행 Action

연구 흐름

  1. 데이터: 질의응답 웹사이트 Quora에서 추출된 질문·답변과, 해당 질문에 대한 GPT-4o·Gemini 2.0 Flash·Claude 3.7 Sonnet·DeepSeek의 생성 답변으로 이루어진 더한 자체 구축 벤치마크 데이터. 클래스에 대한 80:20 층화 분할로 학습·평가에 활용. 동료 연구원에게서 제공받음
  2. Perplexity: Transformers 라이브러리를 활용하여 Llama-3.1-8B로 각 텍스트의 토큰별 조건부 확률을 계산
  3. 피처 통합: 동료 연구자가 설계한 문체 분석 기반 피처(고전적 NLP 통계량), 내용 분석 기반(LDA 토픽) 피처와 Perplexity를 통합하여 총 37차원 피처 벡터 구성
  4. 분류 모델: 표준화한 피처 벡터로 네개 레이어를 가지는 MLP를 학습하여, 다섯 범주에 대한 다중 분류 모델을 구성
  5. 이진 분류: 평가 데이터에서 다섯 범주 확률을 그대로 다중 분류에 활용하거나, 네 개의 LLM 범주 확률을 합산하여 인간/LLM 이진 분류에 활용
  6. 결과 해석: 문체 분석 기반 피처와 Perplexity의 범주별 분포를 시각화하여 인간과 LLM, 개별 LLM 간의 차이를 해석

성과 Result

우수한 분류 성능

  • Perplexity 추가 시 정확도가 이진 분류 0.9599 → 0.9778, 다중 분류 0.8217 → 0.8598로 향상. 오분류율 기준 각각 44.64%, 21.37% 감소
  • Perplexity 단독 모델은 이진 분류 정확도 0.8864로 준수하나 다중 분류에서는 0.4732에 그쳐, 나머지 통계적 피처들이 Perplexity에 없는 LLM 식별 정보를 다수 포함함을 확인

분포 차이 식별

  • 인간: 모든 문체 피처에서 분산이 가장 크고, Perplexity도 LLM보다 평균이 높고 분산이 커 뚜렷이 다른 분포
  • GPT: 문장과 문서가 가장 길고 플레시-킨케이드 가독성 지수가 가장 높아, 읽기 어려운 문장을 구사하는 경향
  • Gemini: 문장 수는 가장 많으나 문장 길이가 가장 짧아, GPT보다 전체 출력이 짧음
  • Claude · DeepSeek: 출력이 짧고 길이가 일정하나 어휘 밀도가 가장 높아, 짧은 분량에 내용을 압축하는 경향
